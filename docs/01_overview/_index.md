# 概要

## 1. 宇宙産業とは

宇宙産業とは，人工衛星，ロケット，宇宙ステーション等の宇宙システムの開発・製造・打ち上げ・運用に関わる産業の総称である．
近年，民間企業の参入（いわゆる「NewSpace」ムーブメント）により，従来の政府・軍主導の産業構造から，商業化・小型化・低コスト化が急速に進んでいる．

## 2. 宇宙産業の市場規模

- 世界の宇宙産業市場規模は約5,460億ドル（2022年，Space Foundation 調査；最新の公開統計値として参照）であり，年率6〜8%で成長が続いている．
- 日本の宇宙産業市場規模は約4兆円（2022年度，内閣府調査；最新の公開統計値として参照）であり，政府は2030年代早期に現在の2倍（約8兆円）規模を目指している．
- 世界市場の構成比は「衛星サービス」が最大（約40%），次いで「地上設備」（約35%），「政府予算（打ち上げ・宇宙機等）」（約25%）となっている．

## 3. 宇宙産業の業界構造（バリューチェーン）

宇宙産業は大きく **アップストリーム（上流）**・**ミッドストリーム（中流）**・**ダウンストリーム（下流）** の3層に分類できる．

├───────────────┼──────────────────────┼───────────────────────────┤

## 4. 宇宙産業のサプライチェーン構造

宇宙産業のサプライチェーンは，航空・防衛産業と類似した **ティア（Tier）構造** を持つ．

```
Tier 0（プライム）：JAXA，SpaceX，Arianespace，三菱重工等
       ↑ システムインテグレーション
Tier 1（主要サブシステムメーカー）：推進系，構造体，電子機器等
       ↑ サブシステム供給
Tier 2（コンポーネントメーカー）：部品，モジュール，センサ等
       ↑ コンポーネント供給
Tier 3（素材・材料メーカー）：CFRP，特殊合金，電子材料等
```

### サプライチェーンの特徴

1. **高品質・高信頼性要求**：宇宙機は打ち上げ後の修理が困難なため，部品・材料に対して極めて高い品質基準（宇宙用グレード）が求められる．
2. **少量生産・高単価**：民間機に比べて生産数が少なく，一品一様の製造が多い．近年は小型衛星の量産化により変化しつつある．
3. **輸出規制（EAR/ITAR）**：宇宙技術の多くが輸出規制（米国ITAR，日本の外為法等）の対象となり，国際調達に制約が生じる．
4. **長いリードタイム**：部品の開発・認定から最終製品納入まで数年単位の期間を要するケースが多い．
5. **デュアルユース性**：宇宙技術の多くは民間・防衛の両方に転用可能なため，調達・管理が複雑になる．

### 5.2 日本の宇宙政策の方向性

- **宇宙基本計画（2023年改訂）**：安全保障，産業振興，国際協力の3本柱
- **H3ロケット**：基幹ロケットの刷新・コスト半減・国際競争力強化
- **準天頂衛星（みちびき）**：高精度測位サービスの提供（7機体制へ拡充）
- **月探査（SLIM，アルテミス計画参加）**：国際協調による月・深宇宙探査
- **宇宙安全保障**：情報収集衛星，早期警戒衛星，宇宙状況把握（SSA）

## 7. サプライチェーン管理アプリケーションへの示唆

本アプリケーションの構築にあたり，以下の観点を設計に反映すべきである：

1. **多層的なサプライヤ管理**：Tier 0〜3のサプライヤ階層を管理できる構造が必要
2. **品目の多様性**：ロケット部品，衛星コンポーネント，材料・素材，ソフトウェアまで幅広く対応
3. **規制情報の管理**：輸出規制（ITAR/EAR/外為法）情報を品目・サプライヤに紐付けて管理
4. **国内外のサプライヤ対応**：日本語・英語両対応，国内外サプライヤの横断検索
5. **技術成熟度（TRL）管理**：部品・技術の開発成熟度レベルを可視化
6. **コスト・リードタイム情報**：調達判断に必要なコスト・納期情報を管理
7. **代替サプライヤ検索**：特定サプライヤへの依存リスクを低減するための代替品・代替先検索機能
