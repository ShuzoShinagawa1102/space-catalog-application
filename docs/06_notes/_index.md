# 調査ノート

## 宇宙産業サプライチェーンに関する調査メモ

### キーワード・用語集

| 用語 | 説明 |
|---|---|
| ITAR（International Traffic in Arms Regulations） | 米国の国際武器取引規制．宇宙機や部品の多くが対象となり，日本企業が米国製部品を調達・再輸出する際に許可が必要 |
| EAR（Export Administration Regulations） | 米国の輸出管理規則．商務省が管轄するデュアルユース品目の輸出を規制 |
| TRL（Technology Readiness Level） | 技術成熟度レベル（1〜9段階）．宇宙機器開発における技術の準備状況を示す指標 |
| バスシステム | 衛星の共通基盤部分（電源，姿勢制御，通信，熱制御等）．ミッション機器（ペイロード）と区別して呼ぶ |
| ペイロード | 衛星の主目的機器（カメラ，通信機，科学観測装置等） |
| GTO（Geostationary Transfer Orbit） | 静止遷移軌道．静止衛星への投入に使う中間軌道 |
| LEO（Low Earth Orbit） | 低軌道（高度200〜2,000km）．小型衛星コンステレーションやISS等が配置 |
| SSA（Space Situational Awareness） | 宇宙状況把握．軌道上のすべての物体（衛星・デブリ等）を監視・追跡する活動 |
| NewSpace | 民間主導・ベンチャー主体の新しい宇宙ビジネスの総称 |
| OldSpace | 従来の政府・防衛省主導・大手企業主体の宇宙産業 |
| コンステレーション | 複数の衛星を組み合わせてサービスを提供する衛星網 |
| CFRP（Carbon Fiber Reinforced Plastics） | 炭素繊維強化プラスチック．軽量・高強度なため宇宙機の構造材として多用される |
| 宇宙デブリ | 役目を終えた衛星や打ち上げロケットの残骸など，軌道上に残る人工物 |
| ADR（Active Debris Removal） | 能動的デブリ除去技術．Astroscale等が開発中 |

### 宇宙産業の分類（品目・サービス別）

宇宙産業のカタログアプリケーションに登録すべき品目・サービスの分類案：

#### A. ハードウェア（部品・コンポーネント）
- A-1. 推進系（エンジン，スラスタ，バルブ，タンク）
- A-2. 構造体（フレーム，パネル，アダプタ，分離機構）
- A-3. 電源系（太陽電池，バッテリ，電源制御装置）
- A-4. 通信機器（アンテナ，トランスポンダ，増幅器，RF機器）
- A-5. 誘導・航法・制御（IMU，スターセンサ，反動ホイール，CMG）
- A-6. 熱制御（ヒータ，熱パイプ，MLI断熱材，ラジエータ）
- A-7. ペイロード（カメラ，SAR，科学観測機器）
- A-8. 電子機器（宇宙用プロセッサ，メモリ，FPGA）

#### B. 材料・素材
- B-1. 構造材料（CFRP，アルミ合金，チタン合金）
- B-2. 耐熱材料（セラミクス，炭素炭素複合材）
- B-3. 電子材料（半導体，基板材料）
- B-4. 推進剤（液体水素，液体酸素，ヒドラジン）

#### C. ソフトウェア
- C-1. フライトソフトウェア（OBC，AOCS）
- C-2. 地上管制ソフトウェア
- C-3. シミュレーション・解析ソフトウェア
- C-4. 衛星データ処理ソフトウェア

#### D. 試験・評価設備・サービス
- D-1. 振動試験
- D-2. 熱真空試験
- D-3. 電波暗室（EMC試験）
- D-4. 音響試験

#### E. 打ち上げサービス
- E-1. 打ち上げ機（ロケット）
- E-2. 射場・発射台
- E-3. 輸送・ハンドリング

#### F. 地上システム・サポートサービス
- F-1. 地上アンテナ・追跡局
- F-2. 衛星運用サービス（TT&C）
- F-3. 保険サービス
- F-4. 認証・コンサルティング

### 日本のスタートアップ企業動向

近年，日本の宇宙スタートアップが急増しており，JAXA等の支援プログラム（JAXA宇宙イノベーションパートナーシッププログラム：J-SPARC）も整備されている．

主要なスタートアップ：
- **ispace**（東京）：月着陸機，宇宙資源探査
- **Astroscale**（東京）：軌道上サービシング，デブリ除去
- **Axelspace**（東京）：小型衛星，衛星データサービス（GRUS衛星）
- **インターステラテクノロジズ**（北海道）：超小型ロケット（MOMO，ZERO）
- **天地人**（東京）：宇宙データ活用（農業，インフラ等）
- **QPS研究所**（福岡）：小型SAR衛星
- **Synspective**（東京）：小型SAR衛星，データ解析
- **ElevationSpace**（宮城）：低軌道利用プラットフォーム（回収型宇宙実験）
- **Space BD**（東京）：宇宙ビジネスプロデューサー，ISS活用・小型衛星放出
